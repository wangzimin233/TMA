# 可直接发送给 Stitch 的 Prompt

请为一个 Telegram Mini App 数字货币交易平台设计一套移动端 UI。

项目定位：


## 视觉风格

整体风格：

```text
深色模式
金融交易感
高信息密度
清晰、轻量、专业
适合 Telegram Mini App 内嵌场景
```

背景：

```text
主背景接近 #171A21
更深层背景接近 #0B0E12
卡片背景接近 #18191D / #1E2025
边框使用低对比深灰
不要使用大面积渐变
不要使用花哨装饰
不要做营销落地页风格
```

主色：

```text
绿色用于买入、做多、正向操作、主要确认按钮
核心参考色：#2FBE85
```

风险色：

```text
红色用于卖出、做空、下跌、亏损、风险状态
核心参考色：#F6475D
```

辅助色：

```text
橙色用于收藏星标、BTC 图标等少量强调
灰色用于次级文字、未选中 Tab、单位和说明
辅助灰蓝可参考 #4F5867
```

字体：

```text
使用系统无衬线字体
数字需要清晰醒目
价格、涨跌幅、按钮文字需要高可读性
避免过度圆润或可爱
```

布局：

```text
移动端宽度按 390px 或 393px 设计
底部导航固定
顶部信息区紧凑
列表行高稳定
按钮和输入框适合拇指点击
避免文字拥挤或重叠
```

## 页面要求

### 1. 首页

首页要突出「快速交易」和「行情概览」。

模块：

```text
快捷入口宫格
活动 Banner
主流币行情卡片
热门币列表
公告入口或滚动公告
底部导航
```

快捷入口建议包含：

```text
邀请好友
福利中心
充值
合约
现货
Superpairs
更多
客服
```

可以参考截图布局，但请让视觉更统一、更适合后续开发。

---

### 2. 行情页

行情页用于浏览交易对。

模块：

```text
顶部主 Tab：自选 / 现货 / 合约 / 榜单
搜索按钮
轻量筛选栏
列表表头：名称 / 最新价 / 涨跌幅
交易对列表
底部导航
```

V1 不需要复杂专区筛选。可以保留：

```text
全部
热门
涨幅榜
跌幅榜
USDT
```

列表项示例：

```text
BTC/USDT
ETH/USDT
BNB/USDT
SOL/USDT
XRP/USDT
UNI/USDT
```

### 3. 交易页 - 下单视图

交易页下单视图是核心页面，需要设计得清晰、稳定、专业。

模块：

```text
顶部：现货 / 合约切换
交易对信息：BTC/USDT、币种图标、下拉箭头
价格信息：最新价、折算价、24H涨跌幅
右侧操作：收藏、K线图标
买入 / 卖出切换
限价 / 市价切换
可用余额
价格输入框
数量输入框
比例选择：0%、25%、50%、75%、100%
交易额输入框
主提交按钮
当前委托
底部导航
```

明确不要出现：

```text
交易机器人
```

买入状态主按钮使用青色，卖出状态可使用红色。
